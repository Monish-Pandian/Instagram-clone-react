# Instagram Clone

A modern Instagram-inspired social media application built using React. This project replicates core Instagram features such as posts, stories, profile management, followers, and user suggestions.

## Features

* User Feed
* Instagram Stories
* User Profile Page
* Followers List
* Suggested Users
* Dark Mode
* React Router Navigation
* JSON Server for Mock Backend

## Tech Stack

### Frontend

* React
* React Router DOM
* Bootstrap
* CSS

### Backend

* JSON Server

## Installation

1. Clone the repository

```bash
git clone https://github.com/Monish-Pandian/Instagram-clone-react.git
```

2. Install dependencies

```bash
npm install
```

3. Start the React application

```bash
npm run dev
```

4. Start JSON Server

```bash
npx json-server --watch db.json --port 3000
```
